# toolkit.mod

BlitzMax NG Toolkit modules. Install this repository as `mod/toolkit.mod` in a BlitzMax NG installation.

## Modules

- [Toolkit.Tourney](tourney.mod/README.md) — configure and play tournaments, generate schedules, record results, and calculate standings.

Import the tournament module with `Import Toolkit.Tourney`. Its [introduction](tourney.mod/doc/intro.bbdoc) covers configuration, results, persistence, and examples.
